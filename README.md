# Customer Segmentation

Unsupervised learning project for identifying meaningful customer segments from credit-card usage behavior using **K-Means, DBSCAN, t-SNE, and PCA**.

## Overview

This project analyzes the usage behavior of approximately **8950 credit-card customers** over a six-month period. The objective is to discover customer segments based on spending, purchasing frequency, cash-advance activity, payment behavior, and credit usage without using predefined labels.

The project covers:

* Data preprocessing and distribution analysis
* Skewness-based feature transformations
* Missing-value handling and feature scaling
* Correlation analysis and feature selection
* K-Means clustering
* DBSCAN clustering
* t-SNE visualization
* PCA-based dimensionality analysis
* PCA reconstruction error evaluation
* Interpretation of customer segments

## Dataset

The dataset is the **Credit Card Dataset for Clustering**, containing 8950 active credit-card customers and 18 columns.

Dataset source:

https://www.kaggle.com/datasets/alirezachahardoli/customer-data-clustring


## Methodology

### 1. Data Preprocessing

The raw data was first inspected for missing values, feature types, distributions, skewness, and correlations.

#### Missing Values

Missing numerical values were handled using **median imputation**, which is more robust to extreme values than mean imputation for highly skewed financial variables.

#### Skewness Analysis

Several financial features exhibited substantial positive skewness due to a small number of customers with very high spending or cash-advance activity.

Examples include:

* `MINIMUM_PAYMENTS`
* `ONEOFF_PURCHASES`
* `PURCHASES`
* `INSTALLMENTS_PURCHASES`
* `PAYMENTS`
* `CASH_ADVANCE`
* `PURCHASES_TRX`

Appropriate transformations such as **logarithmic and power transformations** were applied to reduce skewness and limit the influence of extreme values.

#### Feature Scaling

The transformed numerical variables were standardized using:

$$
z = \frac{x-\mu}{\sigma}
$$

Scaling is particularly important because both K-Means and DBSCAN rely on distances between observations.

#### Correlation Analysis

A correlation matrix was used to identify highly correlated features. Redundant variables were considered for removal to avoid giving excessive importance to closely related behavioral dimensions.

For example, `CASH_ADVANCE`, `CASH_ADVANCE_FREQUENCY`, and `CASH_ADVANCE_TRX` exhibited strong correlations.

## 2. Customer Clustering

### K-Means

K-Means was used to partition customers into groups based on similarity in their standardized behavioral features.

The number of clusters was evaluated across multiple candidate values of **k**.

Two metrics were considered:

* **Inertia** — measures within-cluster compactness
* **Silhouette score** — evaluates both cluster compactness and separation

The analysis identified:

> **Optimal K = 3**

resulting in three customer segments.

### DBSCAN

DBSCAN was used as a complementary density-based clustering method.

Unlike K-Means, DBSCAN:

* Does not require the number of clusters to be specified beforehand
* Groups points based on local density
* Can identify noise/outlier observations

Different combinations of **epsilon (`ε`)** and **MinPts** were evaluated to investigate whether DBSCAN could produce a comparable number of customer segments.

## 3. t-SNE Visualization

Since the customer data exists in a high-dimensional feature space, **t-SNE** was used to project the observations into two dimensions for visualization.

The resulting 2D embedding was colored according to the K-Means cluster assignments.

This provides a visual assessment of whether customers belonging to different clusters occupy distinct regions of the feature space.

> t-SNE is used for visualization only; the cluster assignments are generated by K-Means.

## 4. PCA Analysis

Principal Component Analysis was performed on the standardized behavioral features to investigate whether the dataset could be represented using fewer dimensions while retaining most of its variance.

The explained variance ratios for the principal components were examined.

### Explained Variance

The first three principal components explained approximately:

**55.8% of the total variance**

while the first ten components explained approximately:

**92.95% of the total variance**

This indicates that the dataset has meaningful lower-dimensional structure, although a relatively large number of components is required to preserve most of the information.

### PCA Reconstruction

The original data was reconstructed using different numbers of principal components.

| Components | Reconstruction MSE |
| ---------: | -----------------: |
|          2 |             0.5252 |
|          5 |             0.2997 |
|         10 |             0.0745 |
|         15 |            0.00284 |
|         16 |                 ~0 |

The reconstruction error decreases as more components are retained because less information is discarded during dimensionality reduction.

## Results

![Customer Segmentation](results/customer_segmentation.png)
  * Luxury Spenders: High values in ONEOFF_PURCHASES and PURCHASES; use cards for large, one-time purchases; target with higher credit limits and exclusive rewards
  * Frequent Shoppers: High PURCHASES_FREQUENCY, PURCHASES_TRX, and INSTALLMENTS_PURCHASES; make frequent small transactions; target with rewards like cashback on daily purchases
  * Cash-Heavy Users: High CASH_ADVANCE and CASH_ADVANCE_FREQUENCY, low PURCHASES; prioritize liquidity; target with reduced cash advance fees
    
### K-Means

* Number of customer segments: **3**
* Cluster selection based on **inertia and silhouette analysis**

### PCA

* First 3 components: **~55.8% variance explained**
* First 10 components: **~92.95% variance explained**
* 10-component reconstruction MSE: **~0.075**

### Overall Findings

The analysis demonstrates that credit-card customers exhibit distinct behavioral patterns that can be captured using unsupervised learning. K-Means provides a compact three-segment representation, while DBSCAN provides a density-based comparison. t-SNE helps visualize the resulting segmentation, and PCA shows that much of the variation in customer behavior can be represented using a reduced number of dimensions.
